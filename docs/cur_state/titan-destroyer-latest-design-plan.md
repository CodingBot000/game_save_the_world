# Titan Destroyer 최신 기획서

> **보관 문서 / 현재 기준 아님**<br>
> 현재 게임 시스템은 [`titan-destroyer-game-system-master.md`](titan-destroyer-game-system-master.md)를 기준으로 한다. 이 문서에는 제거된 공격 경로와 오래된 수치가 포함되어 있으므로 이력 및 참고용으로만 사용한다.

최종 갱신일: 2026-06-23

이 문서는 현재 `BattleArena` 구현을 기준으로 한 최신 기획서다. 특히 보스 공격은 기존 5종 탄막형 패턴에서 카이주형 대형 위협 패턴으로 바뀌었기 때문에, 아래의 보스 패턴 섹션을 최신 기준으로 본다.

## 기준 구현 파일

- 전투 흐름: `Assets/_Project/Scripts/Gameplay/BattleController.cs`
- 보스 체력/피격: `Assets/_Project/Scripts/Gameplay/BossController.cs`
- 보스 공격 공통값: `Assets/_Project/Scripts/Gameplay/BossAttackController.cs`
- 보스 패턴: `Assets/_Project/Scripts/Gameplay/BossBulletPatternController.cs`
- 플레이어 전투: `Assets/_Project/Scripts/Gameplay/PlayerCombatController.cs`
- 플레이어 필살기: `Assets/_Project/Scripts/Gameplay/PlayerSpecialAttackController.cs`
- 차량별 방어 스탯: `Assets/Resources/Vehicles/VehiclePlayerStateCatalog.asset`
- 현재 씬 값: `Assets/Scenes/BattleArena.unity/BattleArena.unity`

## 전투 핵심 방향

- 플레이어는 헬기를 조종하며 보스를 중심으로 회피, 사격, 미사일, 필살기를 사용한다.
- 보스는 단순 탄막보다 거대한 괴수의 물리적 위협을 강조한다.
- 보스 공격은 예고 표시가 있는 고위협 패턴 위주로 구성한다.
- 플레이어는 장갑을 통해 실수를 일부 흡수하지만, 장갑 파손 후에는 본체 피해가 커진다.
- 전투 중 이벤트 HUD가 보스 첫 공격, 보스 체력 구간, 필살기 살보 완료에 반응한다.

| 항목 | 현재값 | 비고 |
| --- | ---: | --- |
| 보스 HP | 2000 | 싱글 전투 기준 |
| 보스 HP | 2800 | `MultiPlaceholder` 모드 기준 |

| 보스 기본 투사체 피해 | 15 | 패턴별 `damageMultiplier`가 곱해짐 |
| 보스 투사체 스케일 배율 | 2.5 | 패턴 투사체 스케일과 추가 곱 |
| 보스 첫 패턴 시작 지연 | 4초 | `BattleArena` 씬 직렬화 값 |
| 패턴 세트 | `KaijuHeavyThreats` | 현재 활성 세트 |

공격 간격 계산식:

```text
CurrentAttackInterval = Lerp(0.9, 1.8, BossHealthRatio)
FinalCooldown = CurrentAttackInterval * cooldownMultiplier
```

예시:

| 보스 HP 비율 | 기본 공격 간격 |
| ---: | ---: |
| 100% | 1.8초 |
| 65% | 1.485초 |
| 50% | 1.35초 |
| 33% | 약 1.2초 |
| 0% | 0.9초 |

## 보스 패턴 선택 규칙

- 현재 활성 패턴 세트는 `KaijuHeavyThreats`다.
- 패턴은 랜덤이 아니라 리스트 순서 기반 라운드 로빈으로 선택된다.
- 현재 인덱스부터 시작해, 보스 HP 조건에 맞고 `enabled`인 첫 패턴을 실행한다.
- 실행 후 다음 탐색 시작 인덱스가 다음 칸으로 이동한다.
- 패턴 내부의 조준점, 파편 묶음, 빔 방향 등 일부 요소만 랜덤이다.
- 현재 패턴 실행 중에 디버그 튜닝값을 바꿔도 대체로 다음 패턴부터 안정적으로 반영된다.

현재 활성 순서:

1. `Debris Fragment Scatter`
2. `Debris Salvo`
3. `Accelerating Sweep Beam`
4. `Tracking Residual Beam`

## 보스 패턴 상세

### 1. Debris Fragment Scatter

보스가 발 구르기처럼 짧게 뛰며 파편을 흩뿌리는 패턴이다. 기존 탄막의 작은 탄을 대체하는 저피해 다발 위협 역할이다.

| 항목 | 현재값 |
| --- | ---: |
| HP 조건 | 0% - 100% |
| 쿨다운 배율 | 0.9 |
| 파편 수 | 7 - 10개 |
| 파편 간격 | 0.025초 |
| 속도 배율 | 0.25 |
| 실제 속도 | 6 |
| 피해 배율 | 0.35 |
| 실제 피해 | 5.25 |
| 경고 시간 | 0.25초 값 보유, 현재는 발구르기 연출이 있으면 발구르기 시간이 우선 |
| 경고 폭 | 0.65 |
| 투사체 스케일 | 0.45 |
| 조준 흔들림 | 플레이어 반경의 6배 |
| 안전 반경 | 플레이어 반경의 1배 |
| 파편 시각 두께 | 0.34 |
| 발구르기 횟수 | 2회 |
| 발구르기 1회 시간 | 0.2초 |
| 카메라 흔들림 | 0.1초, 진폭 0.24 |

동작:

- `BossFootDebrisFirePoint1`, `BossFootDebrisFirePoint2` 중 하나를 랜덤으로 사용한다.
- 발사 전 발구르기 연출과 카메라 흔들림이 들어간다.
- 파편은 일부가 플레이어 주변에 묶여 떨어지고, 나머지는 더 넓게 흩어진다.
- `VFX/MonsterDebrisFragmentCatalog`가 있으면 파편별 비주얼 프리팹을 붙인다.

기획 의도:

- 전투 초반부터 반복 가능한 기본 압박 패턴이다.
- 피해량은 낮지만 피격 빈도가 높아 장갑 회복을 방해한다.
- 큰 보스가 발밑의 잔해를 튕겨내는 느낌을 준다.

### 2. Debris Salvo

보스가 큰 파편을 플레이어 주변으로 연속 투척하는 패턴이다. 투사체가 접근하면서 커져 화면 압박을 만든다.

| 항목 | 현재값 |
| --- | ---: |
| HP 조건 | 0% - 100% |
| 쿨다운 배율 | 1.05 |
| 투척 수 | 2 - 4개 |
| 투척 간격 | 0.2초 |
| 속도 배율 | 0.5 |
| 실제 기준 속도 | 12 |
| 초기 접근 속도 배율 | 0.5 |
| 실제 초기 속도 | 6 |
| 접근 목표 시간 | 1초 |
| 피해 배율 | 1.55 |
| 실제 피해 | 23.25 |
| 첫 투척 경고 | 0.3초 |
| 경고 폭 | 0.8 |
| 투사체 스케일 | 2.8 |
| 접근 시작 스케일 | 0.25 |
| 접근 종료 스케일 | 1.19 |
| 조준 흔들림 | 플레이어 반경의 2배 |

투척 수는 보스가 체력을 잃을수록 증가한다.

| 보스 체력 상태 | 투척 수 |
| --- | ---: |
| 체력 손실 0% - 33% 미만 | 2개 |
| 체력 손실 33% - 66% 미만 | 3개 |
| 체력 손실 66% 이상 | 4개 |

동작:

- 첫 투척만 선 경고를 표시한다.
- 이후 투척은 짧은 간격으로 플레이어 주변 랜덤 지점에 날아온다.
- 투사체는 초기에는 작게 보이다가 목표 지점에 접근할수록 커진다.
- 큰 파편 단발 피격의 위협을 담당한다.

기획 의도:

- 단순 탄막보다 "큰 물체를 던지는 보스" 느낌을 강화한다.
- HP가 낮아질수록 투척 수가 늘어 후반 압박이 증가한다.

### 3. Accelerating Sweep Beam

보스가 화면을 가로지르는 빔을 충전 후 쓸어내는 패턴이다.

| 항목 | 현재값 |
| --- | ---: |
| HP 조건 | 0% - 100% |
| 쿨다운 배율 | 1.2 |
| 스윕 각도 | 92도 |
| 피해 배율 | 1.2 |
| 실제 피해 | 18 |
| 충전 경고 | 0.8초 |
| 빔 폭 | 0.78 * 공격 크기 배율 = 1.95 |
| 빔 길이 | 28 * 공격 크기 배율 = 70 |
| 느린 구간 | 0.3초 |
| 빠른 구간 | 0.2초 |
| 총 스윕 시간 | 0.5초 |

동작:

- 좌에서 우 또는 우에서 좌 방향을 랜덤으로 선택한다.
- 카메라가 있으면 플레이어의 화면상 높이를 기준으로 수평 스윕 방향을 계산한다.
- 처음 0.3초 동안 전체 진행도의 20%만 천천히 움직이고, 이후 0.2초 동안 빠르게 끝까지 쓸어낸다.
- 빔 피격은 일반 피해 방식이라 플레이어 무적 시간의 영향을 받는다.

기획 의도:

- 전투 중 가장 명확한 회피 판정 패턴이다.
- 예고를 보고 수직/수평 이동으로 벗어나는 플레이를 요구한다.
- 후반에도 계속 등장해 긴장도를 유지한다.

### 4. Tracking Residual Beam

보스가 입 또는 발사 지점에 에너지를 모은 뒤, 플레이어를 따라오는 잔류 빔을 유지하는 패턴이다.

| 항목 | 현재값 |
| --- | ---: |
| HP 조건 | 0% - 65% |
| 쿨다운 배율 | 1.35 |
| 워밍업 | 0.5초 |
| 추적 지속 | 4초 |
| 추적 속도 | 플레이어 속도의 0.4배 |
| 빔 폭 | 0.62 * 공격 크기 배율 = 1.55 |
| 빔 길이 | 28 * 공격 크기 배율 = 70 |
| 지속 피해 | 0.2초마다 3 |
| 초당 피해 환산 | 15 |

동작:

- HP 65% 이하부터 패턴 순환에 들어온다.
- 워밍업 동안 발사 지점에 구형 차지 경고가 표시된다.
- 발사 후 빔의 조준점이 플레이어 위치를 향해 지속적으로 이동한다.
- 일반 무적 시간과 별개로 `ApplyContinuousDamage`를 사용해 0.2초마다 피해를 준다.

현재 주의점:

- 이 패턴의 `telegraphDuration` 값 0.7초는 현재 실행 로직에서 직접 쓰이지 않고, `fixedDuration` 0.5초가 워밍업 시간으로 사용된다.
- `damageMultiplier` 값 0.95도 지속 피해에는 직접 쓰이지 않는다. 실제 지속 피해는 코드 상수 `3 damage / 0.2 sec`가 기준이다.

기획 의도:

- 후반 전용 추적 압박 패턴이다.
- 한 번 스치면 끝나는 공격이 아니라, 계속 움직여야 하는 지속 위험을 만든다.

## 보스 패턴 페이즈 체감

| 보스 HP 비율 | 등장 가능 패턴 |
| ---: | --- |
| 100% - 65% 초과 | Debris Fragment Scatter, Debris Salvo, Accelerating Sweep Beam |
| 65% 이하 | 위 3개 + Tracking Residual Beam |

현재 보스 패턴은 전통적인 1페이즈/2페이즈 전환보다, 동일 순환에 후반 전용 추적 빔을 추가하는 방식이다.

## 레거시 보스 패턴

아래 패턴들은 아직 `LegacyBulletHell` 세트로 코드와 씬 데이터에 남아 있지만, 현재 활성 세트가 아니므로 최신 전투 기준이 아니다.

- `Fan Spread`
- `Aimed Burst`
- `Spiral Ring`
- `Falling Bomb`
- `Split Shot`

레거시 세트는 디버그나 백업용으로만 본다. 최신 보스 기획과 밸런스 기준은 `KaijuHeavyThreats`다.

## 플레이어 전투/방어 최신 기준

차량별 방어 스탯은 `VehiclePlayerStateCatalog.asset`에서 가져온다. 현재 모든 차량과 fallback이 같은 값을 사용한다.

| 항목 | 현재값 |
| --- | ---: |
| 본체 HP | 100 |
| 장갑 HP | 120 |
| 장갑 회복량 | 초당 8 |
| 장갑 회복 지연 | 마지막 피격 후 2.5초 |
| 장갑 파손 해제 기준 | 장갑 36 이상 |
| 장갑 파손 중 본체 피해 배율 | 1.25 |
| 피격 무적 | 최소 1초 |
| 플레이어 기본 탄 쿨다운 | 0.15초 |
| 플레이어 기본 탄 속도 | 60 |
| 플레이어 기본 탄 피해 | 25 |
| 일반 미사일 쿨다운 | 2.6초 |
| 일반 미사일 피해 | 150 |
| 일반 미사일 명중 반경 | 1.8 |

피해 처리:

- 장갑이 남아 있고 파손 상태가 아니면 장갑이 먼저 피해를 받는다.
- 장갑이 0 이하가 되면 `armorBroken`이 켜진다.
- 장갑 파손 중 본체에 들어가는 남은 피해는 1.25배로 증폭된다.
- 장갑은 마지막 피격 후 2.5초가 지나야 회복된다.
- 장갑이 36 이상 회복되면 파손 상태가 해제된다.

## 플레이어 필살기 최신 기준

필살기는 `PlayerSpecialAttackController`가 런타임에 구성한다.

| 항목 | 현재값 |
| --- | ---: |
| 컷인 시간 | 0.4초 |
| 미사일 살보 시간 | 2초 |
| 시각 복귀 시간 | 0.35초 |
| 보스 방향 회전 연출 | 60도 |
| 좌측 미사일 수 | 15 |
| 우측 미사일 수 | 15 |
| 총 특수 미사일 수 | 30 |
| 발리당 발사 수 | 2 |
| 발리 수 | 15 |
| 발리 간격 | 약 0.143초 |
| 특수 미사일 피해 | 0 |

동작:

- 발동 시 플레이어 입력과 보스 패턴을 일시 정지한다.
- 기존 보스 투사체를 모두 제거한다.
- 상/하 컷인 이미지를 표시한다.
- 양쪽 런처에서 화면 좌우로 벌어지는 사이드 아크 미사일을 발사한다.
- 살보가 끝나면 `SpecialMissileSalvoCompleted` 이벤트를 발생시킨다.

현재 주의점:

- `specialMissileDamage` 기본값이 0이라, 현재 기준 필살기는 피해보다 컷신/연출 성격이 강하다.
- 실제 필살기 피해를 기대한다면 `specialMissileDamage`를 별도 밸런스 값으로 정해야 한다.

## 전투 이벤트 HUD

현재 `BattleArena`에는 전투 이벤트 HUD 두 종류가 있다.

### 방송 HUD

- 오브젝트: `EventBroadcastHud`
- 첫 보스 공격 시작 시 normal 방송 연출을 4초 표시한다.
- 필살기 미사일 살보 완료 시 surprise 방송 연출을 4초 표시한다.
- 애니메이션 프레임 속도는 8 FPS다.

### 대사 HUD

- 오브젝트: `EventDialogueHud`
- 보스 HP가 66.66667% 이하가 되면 angry 프레임을 3초 표시한다.
- 보스 HP가 33.33334% 이하가 되면 normal 프레임을 3초 표시한다.
- 애니메이션 프레임 속도는 8 FPS다.

## 튜닝 우선순위

보스 패턴 밸런스를 조정할 때는 아래 순서로 본다.

1. 전투 템포: `baseAttackInterval`, `enragedAttackInterval`, 패턴별 `cooldownMultiplier`
2. 회피 가능성: `telegraphDuration`, `warningWidth`, `slowDuration`, `fastDuration`, `trackingDuration`
3. 화면 압박량: 파편 수, 투척 수, 빔 폭, 조준 흔들림
4. 피격 리스크: 보스 기본 피해, 패턴별 피해 배율, 추적 빔 지속 피해 상수
5. 후반 긴장도: `Tracking Residual Beam` HP 조건과 지속 시간
