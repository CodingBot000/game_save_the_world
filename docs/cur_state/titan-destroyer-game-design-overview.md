# Titan Destroyer 게임 기획 공유 개요서

> **보관 문서 / 현재 기준 아님**<br>
> 현재 게임 시스템은 [`titan-destroyer-game-system-master.md`](titan-destroyer-game-system-master.md)를 기준으로 한다. 이 문서에는 제거된 단발 미사일, 필살기, 확률 크리티컬 등 과거 규칙이 포함되어 있으므로 현재 구현 판단에 사용하지 않는다.

최종 갱신일: 2026-07-09

이 문서는 Titan Destroyer의 현재 게임 구조, 플레이 스타일, 전투 규칙, 보스 공격 패턴을 다른 사람에게 공유하기 위한 기획 요약 문서다. 구현 방식이나 코드 구조가 아니라, 플레이어가 실제로 경험하는 게임 흐름과 전투 의도를 중심으로 정리한다.

## 1. 게임 핵심 컨셉

Titan Destroyer는 헬기를 조종해 거대한 보스형 타이탄을 상대하는 회피 슈팅 전투 게임이다.

플레이어는 화면 기준 2D 평면 안에서 헬기를 움직이며, 보스의 거대한 물리 공격과 빔 공격을 피하고, 기본탄/미사일/필살기를 사용해 보스를 격파한다. 전투의 핵심 긴장감은 "예고를 보고 피하는 보스 패턴", "장갑을 유지하며 실수를 관리하는 생존 구조", "타겟 선택과 크리티컬 타이밍을 활용하는 공격 판단"에서 나온다.

현재 보스 전투는 작은 탄을 많이 뿌리는 전통 탄막보다, 거대 괴수가 파편을 튕기고, 큰 물체를 던지고, 화면을 가르는 빔을 쏘는 카이주형 대형 위협을 강조한다.

## 2. 전체 게임 흐름

현재 게임의 기본 흐름은 다음과 같다.

1. 메인 메뉴에서 게임 시작, 차고, 파일럿 화면으로 진입한다.
2. 게임 시작 시 스테이지 선택 화면으로 이동한다.
3. 스테이지와 난이도를 선택한 뒤 전투 아레나로 진입한다.
4. 전투에서는 보스 체력을 0으로 만들면 승리하고, 플레이어 본체 체력이 0이 되면 미션 실패가 된다.
5. 미션 실패 후에는 재도전 또는 메인 메뉴 복귀를 선택한다.

현재 스테이지 선택 화면에는 5개 지역이 존재한다.

| 스테이지 | 지역명 |
| ---: | --- |
| Stage 1 | Tokyo |
| Stage 2 | Seoul |
| Stage 3 | Paris |
| Stage 4 | Hollywood |
| Stage 5 | Beijing |

난이도 선택은 4단계로 구성되어 있다.

| 표시 | 난이도 |
| ---: | --- |
| 1 | Easy |
| 2 | Normal |
| 3 | Expert |
| 4 | Nightmare |

현재 공유 기준에서는 스테이지와 난이도 선택이 전투 진입 전 선택 요소로 존재한다. 난이도별 세부 밸런스 차등은 별도 기획 확정이 필요한 항목으로 본다.

## 3. 현재 플레이 모드

현재 전투 모드는 두 가지 기준으로 나뉜다.

| 모드 | 현재 역할 | 보스 HP |
| --- | --- | ---: |
| Single | 기본 1인 전투 | 2000 |
| MultiPlaceholder | 협동전 가정용 플레이스홀더 | 2800 |

MultiPlaceholder는 보스 체력이 더 높고 아군 플레이스홀더가 표시되는 형태다. 현재 기준으로는 완성된 협동전 규칙이라기보다, 향후 멀티/협동 구조를 염두에 둔 전투 변형으로 보는 것이 적절하다.

## 4. 플레이어 조작과 전투 스타일

플레이어는 헬기를 화면 기준 2D 평면에서 조작한다. 좌우/상하 이동 중에는 헬기 모델만 살짝 기울어져 속도감과 방향감을 준다.

| 입력 | 역할 |
| --- | --- |
| A / D 또는 방향키 좌우 | 좌우 이동 |
| W / S 또는 방향키 상하 | 상하 이동 |
| Space 또는 마우스 좌클릭 | 기본탄 발사 |
| 마우스 우클릭 또는 미사일 버튼 | 유도 미사일 발사 |
| Special 버튼 | 필살기 발동 |
| R | 전투 재시작 |

플레이 감각은 고정된 화면 안에서 회피 공간을 관리하는 방식에 가깝다. 플레이어는 보스 주변을 자유롭게 3D로 비행한다기보다, 카메라에 보이는 전투 화면 안에서 예고 범위를 읽고 이동한다.

## 5. 플레이어 공격 수단

### 기본탄

기본탄은 지속적으로 보스를 압박하는 주 공격 수단이다.

| 항목 | 현재값 |
| --- | ---: |
| 발사 간격 | 0.15초 |
| 탄속 | 60 |
| 피해량 | 25 |
| 기본 크리티컬 확률 | 5% |

기본탄은 연사형 무기이므로, 플레이어가 회피 중에도 계속 공격을 유지하는 플레이를 만든다.

### 유도 미사일

미사일은 쿨다운이 있는 고피해 공격 수단이다.

| 항목 | 현재값 |
| --- | ---: |
| 쿨다운 | 2.6초 |
| 피해량 | 150 |
| 명중 반경 | 1.8 |
| 발사 방식 | 좌/우 런처 교대 발사 |

미사일은 선택된 타겟을 추적한다. 기본탄보다 한 방의 의미가 크기 때문에, 크리티컬 타이밍 또는 보스 패턴 회피 직후에 맞추는 판단 요소가 된다.

### 필살기

필살기는 전투 흐름을 잠시 멈추고 컷인과 미사일 살보를 보여주는 연출형 공격이다.

| 항목 | 현재값 |
| --- | ---: |
| 컷인 시간 | 0.4초 |
| 미사일 살보 시간 | 2초 |
| 복귀 시간 | 0.35초 |
| 총 미사일 수 | 30발 |
| 발리당 발사 수 | 2발 |
| 특수 미사일 피해 | 0 |

현재 필살기는 보스 공격을 일시 정지하고 화면의 보스 투사체를 제거한 뒤, 대량 미사일 연출을 보여주는 성격이 강하다. 실제 피해를 주는 궁극기로 사용할지, 전투 리듬을 끊는 연출/회피 보조기로 사용할지는 추가 기획 결정이 필요하다.

## 6. 타겟 선택과 크리티컬 구조

보스에는 여러 개의 조준 포인트가 있으며, 전투 중 화면에 타겟 마커로 표시된다.

플레이어는 타겟 마커를 클릭하거나 터치해 공격 목표를 선택할 수 있다. 선택된 타겟은 기본탄과 미사일의 우선 목표가 된다. 선택 전에는 기본 타겟 또는 보스 중심부를 향해 공격한다.

전투 중 5초마다 선택되지 않은 타겟 중 하나가 크리티컬 타이밍 대상으로 지정된다.

| 상태 | 의미 |
| --- | --- |
| 일반 타겟 | 기본 조준 가능 지점 |
| 크리티컬 타이밍 타겟 | 일정 시간 동안 명중 시 크리티컬 확률 증가 |
| 선택 타겟 | 플레이어가 직접 지정한 공격 목표 |

크리티컬 확률은 다음과 같다.

| 상황 | 크리티컬 확률 |
| --- | ---: |
| 일반 명중 | 5% |
| 크리티컬 타이밍 타겟에 맞춘 발사 | 20% |

현재 크리티컬 피해는 2배로 적용된다.

이 구조의 목적은 플레이어가 단순히 보스 중심만 쏘는 것이 아니라, 화면에 나타나는 타겟 상태를 보고 공격 목표를 바꾸는 판단을 하게 만드는 것이다.

## 7. 플레이어 생존 구조

플레이어 생존은 본체 HP와 장갑 HP의 2중 구조다.

| 항목 | 현재값 |
| --- | ---: |
| 본체 HP | 100 |
| 장갑 HP | 120 |
| 장갑 회복량 | 초당 8 |
| 장갑 회복 시작 조건 | 마지막 피격 후 2.5초 |
| 장갑 파손 해제 기준 | 장갑 36 이상 |
| 장갑 파손 중 본체 피해 배율 | 1.25배 |
| 피격 후 무적 시간 | 최소 1초 |

피해는 장갑이 먼저 받는다. 장갑이 남아 있는 동안에는 실수를 어느 정도 흡수할 수 있지만, 장갑이 0이 되면 파손 상태가 된다. 파손 상태에서는 본체가 직접 피해를 받고, 받는 피해도 증가한다.

장갑은 마지막 피격 후 일정 시간이 지나야 회복되기 시작한다. 따라서 이 게임의 생존 플레이는 "계속 맞으며 버티기"가 아니라, 피격 후 잠시라도 잘 피해서 장갑을 회복시키는 방식으로 설계되어 있다.

## 8. 보스 전투 구조

현재 보스는 카이주형 대형 위협 패턴 세트를 사용한다.

| 항목 | 현재값 |
| --- | ---: |
| 싱글 모드 보스 HP | 2000 |
| MultiPlaceholder 보스 HP | 2800 |
| 첫 패턴 시작 지연 | 4초 |
| 보스 기본 공격 간격 | 1.8초 |
| 보스 분노 공격 간격 | 0.9초 |
| 보스 기본 투사체 속도 | 24 |
| 보스 기본 투사체 피해 | 15 |
| 공격 크기 배율 | 2.5 |

보스 공격 템포는 보스 체력이 낮아질수록 빨라진다.

| 보스 HP 비율 | 기본 공격 간격 |
| ---: | ---: |
| 100% | 1.8초 |
| 65% | 약 1.49초 |
| 50% | 1.35초 |
| 33% | 약 1.2초 |
| 0% | 0.9초 |

패턴은 완전 랜덤이 아니라 정해진 순서 기반으로 순환한다. 다만 각 패턴 안에서 조준 지점, 파편 위치, 빔 방향 같은 일부 요소는 달라질 수 있다.

현재 활성 패턴 순서는 다음과 같다.

1. Debris Fragment Scatter
2. Debris Salvo
3. Pressure Sniper Shot
4. Accelerating Sweep Beam
5. Tracking Residual Beam

보스 체력에 따른 체감 페이즈는 다음과 같다.

| 보스 HP 비율 | 등장 가능 패턴 |
| ---: | --- |
| 100% - 65% 초과 | Debris Fragment Scatter, Debris Salvo, Pressure Sniper Shot, Accelerating Sweep Beam |
| 65% 이하 | 위 4종 + Tracking Residual Beam |

현재 구조는 전통적인 1페이즈/2페이즈 변신 구조라기보다, 보스 체력이 낮아질수록 공격 간격이 짧아지고 후반 전용 지속 추적 빔이 추가되는 방식이다.

## 9. 보스 공격 패턴 상세

### 9.1 Debris Fragment Scatter

보스가 발 구르기처럼 짧게 뛰며 작은 파편을 흩뿌리는 기본 압박 패턴이다.

| 항목 | 현재값 |
| --- | ---: |
| 등장 조건 | HP 0% - 100% |
| 쿨다운 배율 | 0.9 |
| 파편 수 | 7 - 10개 |
| 파편 간격 | 0.025초 |
| 실제 속도 | 6 |
| 실제 피해 | 5.25 |
| 발구르기 | 2회 |
| 발구르기 1회 시간 | 0.2초 |
| 카메라 흔들림 | 0.1초, 진폭 0.24 |

기획 의도:

- 전투 초반부터 반복되는 저피해 다발 위협이다.
- 피해량은 낮지만 피격 빈도가 높아 장갑 회복을 방해한다.
- 작은 탄막이 아니라, 거대한 보스가 발밑 잔해를 튕겨내는 느낌을 준다.

플레이어 대응:

- 파편이 몰리는 방향을 보고 짧게 빠져나간다.
- 한두 대 맞더라도 장갑이 회복될 시간을 확보하는 것이 중요하다.

### 9.2 Debris Salvo

보스가 큰 파편을 플레이어 주변으로 연속 투척하는 패턴이다.

| 항목 | 현재값 |
| --- | ---: |
| 등장 조건 | HP 0% - 100% |
| 쿨다운 배율 | 1.05 |
| 투척 수 | 2 - 4개 |
| 투척 간격 | 0.2초 |
| 실제 기준 속도 | 12 |
| 접근 목표 시간 | 1초 |
| 실제 피해 | 23.25 |
| 첫 투척 경고 | 0.3초 |
| 투사체 스케일 | 2.8 |

투척 수는 보스 체력이 낮아질수록 증가한다.

| 보스 체력 손실 | 투척 수 |
| --- | ---: |
| 0% - 33% 미만 | 2개 |
| 33% - 66% 미만 | 3개 |
| 66% 이상 | 4개 |

기획 의도:

- 큰 물체가 날아오는 화면 압박을 만든다.
- 보스 체력이 낮아질수록 같은 패턴도 더 위험하게 느껴진다.

플레이어 대응:

- 첫 경고 위치를 보고 이동을 시작한다.
- 이후 연속 투척은 플레이어 주변을 따라오므로, 한 방향으로만 몰리지 않게 이동한다.

### 9.3 Pressure Sniper Shot

보스가 플레이어 위치를 잠깐 고정 조준한 뒤, 매우 빠른 압력탄을 발사하는 저격형 패턴이다.

| 항목 | 현재값 |
| --- | ---: |
| 등장 조건 | HP 0% - 100% |
| 쿨다운 배율 | 1.25 |
| 발사 수 | 1발 |
| 속도 배율 | 10 |
| 실제 속도 | 240 |
| 피해 배율 | 2.2 |
| 실제 피해 | 33 |
| 경고 시간 | 0.7초 |
| 경고 점멸 간격 | 0.12초 |
| 경고 반경 기준 | 1.9 |
| 풍압 밀림 거리 | 1.15 |
| 풍압 밀림 시간 | 0.18초 |

기획 의도:

- 단순히 맞으면 아픈 탄이 아니라, 근접 통과만 해도 플레이어 조작을 흔드는 압력 공격이다.
- 정지해 있거나 늦게 반응하는 플레이어를 강하게 압박한다.
- 다른 광역 패턴 사이에 짧고 날카로운 긴장 피크를 만든다.

플레이어 대응:

- 원형 경고가 뜨면 즉시 표시 범위에서 벗어난다.
- 직격을 피하더라도 너무 가깝게 스치면 풍압으로 밀릴 수 있으므로 여유 거리를 둔다.

### 9.4 Accelerating Sweep Beam

보스가 화면을 가로지르는 빔을 충전한 뒤, 한 방향으로 쓸어내는 패턴이다.

| 항목 | 현재값 |
| --- | ---: |
| 등장 조건 | HP 0% - 100% |
| 쿨다운 배율 | 1.2 |
| 스윕 각도 | 92도 |
| 실제 피해 | 18 |
| 충전 경고 | 0.8초 |
| 빔 폭 | 1.95 |
| 빔 길이 | 70 |
| 느린 구간 | 0.3초 |
| 빠른 구간 | 0.2초 |
| 총 스윕 시간 | 0.5초 |

기획 의도:

- 전투 중 가장 명확한 회피 판정 패턴이다.
- 예고를 보고 수직/수평 이동으로 벗어나는 기본 회피 실력을 요구한다.
- 후반에도 계속 등장해, 플레이어가 보스의 큰 공격을 계속 의식하게 만든다.

플레이어 대응:

- 충전 경고를 보고 빔 라인에서 벗어난다.
- 초반은 느리지만 후반에 빠르게 쓸리므로, 늦게 움직이면 피하기 어렵다.

### 9.5 Tracking Residual Beam

보스가 에너지를 모은 뒤, 플레이어를 따라오는 잔류 빔을 일정 시간 유지하는 후반 전용 패턴이다.

| 항목 | 현재값 |
| --- | ---: |
| 등장 조건 | HP 65% 이하 |
| 쿨다운 배율 | 1.35 |
| 워밍업 | 0.5초 |
| 추적 지속 | 4초 |
| 추적 속도 | 플레이어 속도의 0.4배 |
| 빔 폭 | 1.55 |
| 빔 길이 | 70 |
| 지속 피해 | 0.2초마다 3 |
| 초당 피해 환산 | 15 |

기획 의도:

- 후반 전투의 지속 압박을 담당한다.
- 한 번 피하면 끝나는 공격이 아니라, 일정 시간 계속 움직이게 만든다.
- 다른 패턴보다 플레이어의 이동 경로 관리와 화면 끝 몰림 방지가 중요하다.

플레이어 대응:

- 빔이 켜진 뒤에는 한 위치에 오래 머무르지 않는다.
- 화면 가장자리로 몰리면 다음 회피 방향이 줄어들기 때문에, 중앙 회복 이동을 의식한다.

## 10. 전투 HUD와 이벤트 연출

전투 HUD는 플레이어 본체/장갑 상태, 보스 HP, 미사일 버튼, 필살기 버튼, 상태 메시지를 보여준다.

전투 중 이벤트성 HUD도 존재한다.

| 이벤트 | 연출 |
| --- | --- |
| 첫 보스 공격 시작 | 방송 HUD normal 연출 4초 |
| 필살기 미사일 살보 완료 | 방송 HUD surprise 연출 4초 |
| 보스 HP 66.7% 이하 | 대사 HUD angry 프레임 3초 |
| 보스 HP 33.3% 이하 | 대사 HUD normal 프레임 3초 |

이 연출들은 전투 상황의 전환점을 플레이어에게 알려주는 역할을 한다. 특히 보스 HP 구간 연출은 명시적인 페이즈 전환이 크지 않은 현재 구조에서 후반 진입감을 보완한다.

## 11. 현재 밸런스 방향

현재 전투 밸런스는 다음 방향을 목표로 한다.

- 기본 피격 한두 번은 즉사로 이어지지 않는다.
- 연속 피격은 장갑 파손으로 이어지고, 이후 본체가 빠르게 위험해진다.
- 플레이어가 잠시 잘 피하면 장갑이 회복되어 다시 안정권에 들어갈 수 있다.
- 보스 패턴은 대부분 예고를 제공하지만, 예고 후에는 명확한 위치 이동을 요구한다.
- 후반에는 공격 간격이 빨라지고 추적 빔이 추가되어 압박이 커진다.
- 타겟 선택과 크리티컬 타이밍은 공격 효율을 높이는 선택 요소로 작동한다.

## 12. 공유 시 참고할 미정 항목

아래 항목은 현재 구조에는 존재하지만, 기획 확정 또는 추가 검증이 필요한 부분이다.

- 난이도 1-4가 전투 수치에 어떤 차이를 줄지 정해야 한다.
- 필살기를 피해형 궁극기로 쓸지, 연출/위기 탈출형 기능으로 둘지 정해야 한다.
- MultiPlaceholder를 실제 협동전으로 확장할 경우, 보스 HP 외의 역할 분담과 보상 구조가 필요하다.
- 각 스테이지별 보스, 배경, 패턴 차별화가 필요하다.
- 현재 최신 기준은 카이주형 5종 패턴이며, 과거 탄막형 패턴은 현 전투 기준에서 제외한다.
