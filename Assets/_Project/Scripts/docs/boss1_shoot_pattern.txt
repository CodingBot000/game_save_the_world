Boss 1 Shoot Pattern Notes

기준
- 현재 실제 전투 기준은 BattleArena 씬의 BossPlaceholder에 붙은
  BossAttackController + BossBulletPatternController 값이다.
- 관련 파일
  - Assets/_Project/Scripts/Gameplay/BossAttackController.cs
  - Assets/_Project/Scripts/Gameplay/BossBulletPatternController.cs
  - Assets/Prefabs/Characters/BossPlaceholder.prefab
  - Assets/Scenes/BattleArena.unity/BattleArena.unity


1. 공통 기본값

- Boss Max HP: 2000
- Base Attack Interval: 1.8초
- Enraged Attack Interval: 0.9초
- Base Projectile Speed: 24
- Base Projectile Damage: 15
- Pattern startupDelay: 1.0초
- Aimed Burst 기본 연사 간격 fallback: 0.14초
- Aimed Burst 경고 레이저 두께: 0.045


2. 공통 계산식

- 현재 공격 간격
  CurrentAttackInterval = Lerp(0.9, 1.8, BossHealthRatio)

- 예시
  - Boss HP 2000 / 2000 -> 1.8초
  - Boss HP 1600 / 2000 -> 1.62초
  - Boss HP 1000 / 2000 -> 1.35초
  - Boss HP 500 / 2000 -> 1.125초
  - Boss HP 0 / 2000 -> 0.9초

- 패턴 최종 쿨타임
  FinalCooldown = CurrentAttackInterval * cooldownMultiplier

- 패턴 최종 탄속
  FinalSpeed = BaseProjectileSpeed(24) * speedMultiplier

- 패턴 최종 데미지
  FinalDamage = BaseProjectileDamage(15) * damageMultiplier

- Split Shot 분열 후 탄속
  FinalSecondarySpeed = 24 * secondarySpeedMultiplier

- Split Shot 분열 후 데미지
  FinalSecondaryDamage = 15 * secondaryDamageMultiplier


3. 패턴 선택 규칙

- patternSequence 순서대로 돈다.
- 랜덤 선택이 아니다.
- 현재 index부터 다음 패턴을 찾고, HP 조건에 맞는 첫 패턴을 실행한다.
- 실행 후 다음 탐색 시작 index가 다음 칸으로 이동한다.
- HP 구간이 겹치면 순환하면서 번갈아 나올 수 있다.

현재 순서
1) Fan Spread
2) Aimed Burst
3) Spiral Ring
4) Falling Bomb
5) Split Shot


4. 현재 패턴별 숫자

4-1. Fan Spread
- HP Ratio 조건: 0.50 ~ 1.00
- 현재 HP 환산: 1000 ~ 2000
- cooldownMultiplier: 1.0
- projectileCount: 7
- burstCount: 3
- burstInterval: 0.4초
- spreadAngle: 60도
- speedMultiplier: 0.5
- damageMultiplier: 1.0
- 실제 탄속: 12
- 실제 데미지: 15
- 비고: 현재 초반 기본 패턴

4-2. Aimed Burst
- HP Ratio 조건: 0.40 ~ 1.00
- 현재 HP 환산: 800 ~ 2000
- cooldownMultiplier: 0.95
- projectileCount: 3
- burstCount: 1
- burstInterval: 0.14초
- speedMultiplier: 1.3
- damageMultiplier: 0.9
- telegraphDuration: 0.3초
- warningLineThickness: 0.045
- 실제 탄속: 31.2
- 실제 데미지: 13.5
- 비고: 플레이어 방향으로 얇은 빨간 레이저 예고 후 3점사

4-3. Spiral Ring
- HP Ratio 조건: 0.25 ~ 0.80
- 현재 HP 환산: 500 ~ 1600
- cooldownMultiplier: 1.2
- projectileCount: 12
- burstCount: 1
- spreadAngle: 30
- speedMultiplier: 0.8
- damageMultiplier: 0.8
- ringRotationStep: 18도
- 실제 탄속: 19.2
- 실제 데미지: 12
- 비고: 보스 중심 원형 방사, 다음 발사 때 시작 각도가 18도 회전

4-4. Falling Bomb
- HP Ratio 조건: 0.00 ~ 0.55
- 현재 HP 환산: 0 ~ 1100
- cooldownMultiplier: 1.25
- projectileCount: 1
- speedMultiplier: 1.0
- damageMultiplier: 1.8
- telegraphDuration: 2.0초
- flashingDuration: 0.6초
- warningWidth: 2.8
- warningHeight: 10
- warningDepth: 1.4
- overheadHeight: 12
- 실제 데미지: 27
- 비고
  - 현재 구현은 플레이어 위치에 세로 박스를 띄워 경고 후 타격한다.
  - flashing은 0.1초 간격으로 색이 번갈아 바뀐다.
  - overheadHeight는 현재 코드상 노출만 되어 있고 실제 계산에는 아직 사용되지 않는다.

4-5. Split Shot
- HP Ratio 조건: 0.00 ~ 0.45
- 현재 HP 환산: 0 ~ 900
- cooldownMultiplier: 1.1
- projectileCount: 1
- secondaryProjectileCount: 5
- spreadAngle: 70도
- speedMultiplier: 0.6
- secondarySpeedMultiplier: 0.9
- damageMultiplier: 0.9
- secondaryDamageMultiplier: 0.75
- splitDistance: 11
- 실제 1차 탄속: 14.4
- 실제 1차 데미지: 13.5
- 실제 분열 후 탄속: 21.6
- 실제 분열 후 데미지: 11.25
- 비고: 1차 탄이 11 유닛 이동 후 5갈래로 분열


5. 현재 숫자를 바꿀 때 주로 보는 항목

- 공격 빈도 조절
  - BossAttackController
    - baseAttackInterval
    - enragedAttackInterval
  - BossBulletPatternController / 각 패턴
    - cooldownMultiplier

- 한 번에 화면을 채우는 양 조절
  - projectileCount
  - secondaryProjectileCount
  - burstCount
  - burstInterval
  - spreadAngle

- 피하기 어려운 정도 조절
  - speedMultiplier
  - secondarySpeedMultiplier
  - telegraphDuration
  - warningLineThickness
  - splitDistance
  - warningWidth
  - warningDepth

- 맞았을 때 아픈 정도 조절
  - damageMultiplier
  - secondaryDamageMultiplier

- 어느 체력 구간에서 나오는지 조절
  - minHealthRatio
  - maxHealthRatio


6. 현재 미사용 또는 주의할 값

- overheadHeight
  - 인스펙터에는 보이지만 현재 Falling Bomb 계산에 실제 사용되지 않음

- spreadAngle
  - Spiral Ring에서는 현재 실제 발사에 직접 쓰지 않음
  - Spiral Ring은 projectileCount와 ringRotationStep 영향이 더 큼

- secondaryProjectileCount / secondarySpeedMultiplier / secondaryDamageMultiplier
  - Split Shot에서만 사용


7. 빠른 튜닝 예시

- Fan Spread를 덜 빡세게
  - speedMultiplier를 더 낮춘다
  - projectileCount를 줄인다
  - burstCount를 줄인다
  - burstInterval을 늘린다

- Aimed Burst를 더 피하기 쉽게
  - telegraphDuration을 늘린다
  - projectileCount를 줄인다
  - speedMultiplier를 낮춘다

- Spiral Ring을 더 화려하게
  - projectileCount를 늘린다
  - ringRotationStep을 키운다
  - cooldownMultiplier를 줄인다

- Falling Bomb를 더 위협적으로
  - warningWidth를 넓힌다
  - telegraphDuration을 줄인다
  - damageMultiplier를 올린다

- Split Shot를 더 공간통제형으로
  - splitDistance를 더 짧게 해서 빨리 분열
  - secondaryProjectileCount를 늘린다
  - spreadAngle를 넓힌다
