Boss 1 Shoot Pattern Notes
최종 갱신일: 2026-06-23

최신 전체 기획서는 아래 파일을 기준으로 한다.

- docs/titan-destroyer-latest-design-plan.md

이 파일은 보스 1 공격 패턴만 빠르게 확인하기 위한 요약본이다.

1. 현재 기준

- 현재 실제 전투 기준은 BattleArena 씬의 BossPlaceholder에 붙은 BossAttackController + BossBulletPatternController 값이다.
- 현재 활성 패턴 세트는 LegacyBulletHell이 아니라 KaijuHeavyThreats다.
- 보스 HP는 싱글 전투 기준 2000, MultiPlaceholder 모드 기준 2800이다.
- Base Attack Interval은 1.8초, Enraged Attack Interval은 0.9초다.
- Base Projectile Speed는 24, Base Projectile Damage는 15다.
- BattleArena 씬의 Pattern startupDelay는 4초다.
- 공격 크기 배율 attackSizeMultiplier는 2.5다.

2. 공통 계산식

CurrentAttackInterval = Lerp(0.9, 1.8, BossHealthRatio)
FinalCooldown = CurrentAttackInterval * cooldownMultiplier
FinalSpeed = BaseProjectileSpeed(24) * speedMultiplier
FinalDamage = BaseProjectileDamage(15) * damageMultiplier

3. 패턴 선택 규칙

- kaijuHeavyThreatSequence 순서대로 돈다.
- 랜덤 선택이 아니다.
- 현재 index부터 다음 패턴을 찾고, HP 조건에 맞는 첫 패턴을 실행한다.
- 실행 후 다음 탐색 시작 index가 다음 칸으로 이동한다.
- 패턴 내부의 조준점, 파편 묶음, 빔 방향 등 일부 요소만 랜덤이다.

현재 순서

1) Debris Fragment Scatter
2) Debris Salvo
3) Accelerating Sweep Beam
4) Tracking Residual Beam

4. 현재 패턴별 숫자

4-1. Debris Fragment Scatter

- HP Ratio 조건: 0.00 ~ 1.00
- cooldownMultiplier: 0.9
- projectileCount / secondaryProjectileCount: 10 / 7
- 실제 파편 수: 7 ~ 10
- burstInterval: 0.025초
- speedMultiplier: 0.25
- 실제 속도: 6
- damageMultiplier: 0.35
- 실제 피해: 5.25
- telegraphDuration: 0.25초
- warningWidth: 0.65
- projectileScale: 0.45
- aimJitterPlayerScale: 6
- safeRadius: 1
- hazardThickness: 0.34
- 발구르기: 2회, 회당 0.2초
- 비고:
  - BossFootDebrisFirePoint1 또는 BossFootDebrisFirePoint2에서 발사한다.
  - 발구르기 연출이 켜져 있으면 경고 시간보다 발구르기 시간이 실질 대기 시간이 된다.
  - 일부 파편은 플레이어 주변에 뭉치고, 나머지는 넓게 흩어진다.

4-2. Debris Salvo

- HP Ratio 조건: 0.00 ~ 1.00
- cooldownMultiplier: 1.05
- projectileCount / secondaryProjectileCount: 4 / 2
- 실제 투척 수: 2 ~ 4
- burstInterval: 0.2초
- speedMultiplier: 0.5
- 실제 기준 속도: 12
- approachInitialSpeedMultiplier: 0.5
- 실제 초기 속도: 6
- approachFlightDuration: 1초
- damageMultiplier: 1.55
- 실제 피해: 23.25
- telegraphDuration: 0.3초
- warningWidth: 0.8
- projectileScale: 2.8
- approachStartScale: 0.25
- approachEndScale: 1.19
- aimJitterPlayerScale: 2
- 비고:
  - 첫 투척만 경고선을 표시한다.
  - 보스 체력 손실이 커질수록 투척 수가 2개에서 4개까지 증가한다.
  - 투사체는 접근하면서 커지고, 목표 위치에 맞춰 가속된다.

4-3. Accelerating Sweep Beam

- HP Ratio 조건: 0.00 ~ 1.00
- cooldownMultiplier: 1.2
- spreadAngle: 92도
- damageMultiplier: 1.2
- 실제 피해: 18
- telegraphDuration: 0.8초
- warningWidth: 0.78
- 실제 빔 폭: 1.95
- hazardRadius: 28
- 실제 빔 길이: 70
- slowDuration: 0.3초
- fastDuration: 0.2초
- 실제 스윕 시간: 0.5초
- 비고:
  - 좌우 방향은 랜덤이다.
  - 카메라가 있으면 플레이어 화면 높이에 맞춰 수평 스윕한다.
  - 앞 0.3초는 느리게 20%만 진행하고, 뒤 0.2초에 빠르게 끝까지 쓸어낸다.

4-4. Tracking Residual Beam

- HP Ratio 조건: 0.00 ~ 0.65
- cooldownMultiplier: 1.35
- fixedDuration: 0.5초
- trackingDuration: 4초
- beamActiveTrackingSpeedMultiplier: 0.4
- warningWidth: 0.62
- 실제 빔 폭: 1.55
- hazardRadius: 28
- 실제 빔 길이: 70
- 지속 피해: 0.2초마다 3
- 초당 피해 환산: 15
- 비고:
  - 보스 HP 65% 이하부터 등장한다.
  - 발사 지점에 구형 차지 경고를 띄운 뒤 추적 빔을 유지한다.
  - 빔 조준점은 플레이어 위치를 향해 플레이어 속도의 0.4배로 따라온다.
  - 현재 telegraphDuration 0.7과 damageMultiplier 0.95는 이 패턴의 실제 지속 피해 계산에 직접 쓰이지 않는다.

5. 레거시 패턴

아래 패턴은 아직 patternSequence에 남아 있지만 현재 활성 세트가 아니다.

- Fan Spread
- Aimed Burst
- Spiral Ring
- Falling Bomb
- Split Shot

레거시 패턴 값은 이전 메모와 디버그 백업용으로만 본다. 최신 보스 1 전투 기준은 KaijuHeavyThreats다.
