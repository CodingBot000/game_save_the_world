이건 처음부터 절대값보다 전투 체감 시간 기준으로 잡는 게 맞다.핵심 목표를 먼저 정하면:
	•	일반적인 기본 탄 1발은 “아프지만 버틸 수 있음”
	•	연속 3~5발 맞으면 위험해짐
	•	잠깐 잘 피하면 장갑이 다시 복구됨
	•	장갑 깨진 뒤에는 매우 긴장되어야 함
	•	초보도 바로 죽지 않고, 고수는 거의 안 맞고 유지 가능
이 방향이 기존 기획의 “회피 가능하지만 일부 피격을 전제로 한 구조”와 잘 맞다.
1. 기준이 되는 기본 탄막 데미지
먼저 몬스터의 기본 탄막 1발을 기준 단위로 두자.
기본 탄막 1발 데미지
	•	BaseBulletDamage = 12
이 12를 기준으로 모든 걸 잡으면 좋다.
의도:
	•	장갑에 12씩 들어오면 몇 발은 버티지만 무시 못함
	•	1발 맞았다고 억울하지 않음
	•	2~3발 연속 피격하면 “아 위험하다” 느낌이 남

2. 플레이어 기본 상태값 추천
권장 기본값
HullHP
	•	HullHP = 100
설명:
	•	본체 체력은 작게 잡는 게 좋다
	•	장갑이 깨진 뒤에는 긴장감이 확 살아야 함
	•	100은 직관적이고 튜닝하기 쉬움

ArmorHP
	•	ArmorHP = 120
설명:
	•	장갑이 본체보다 약간 높게
	•	실제 전투에서 장갑이 “첫 번째 생존층” 역할을 확실히 해야 함
	•	기본탄 10발 정도면 장갑이 다 깨짐
계산:
	•	120 / 12 = 10발
즉,
	•	초보자는 몇 대 맞고도 버틸 수 있음
	•	고수는 장갑을 유지하면서 싸울 수 있음

ArmorBroken
	•	ArmorBroken = ArmorHP <= 0
이건 상태값이라 수치 기본값보단 판정 기준만 잡으면 된다.
추천 규칙:
	•	장갑 0 이하가 되면 즉시 true
	•	장갑이 일정량 이상 회복되기 전까지 계속 broken 상태 유지

RepairRate
	•	RepairRate = 8 / sec
설명:
	•	초당 8이면 너무 빠르지도 느리지도 않음
	•	기본탄 1발 데미지(12)를 회복하려면 약 1.5초 필요
	•	즉 “조금만 피하면 금방 안정”, “계속 맞으면 절대 못 버팀”
계산:
	•	장갑 120 풀복구 = 15초
	•	하지만 실제 플레이에선 전체를 다 채우기보다 일부 회복만 자주 일어남
이 감각이 좋다:
	•	숨 돌릴 시간 확보 시 복구
	•	맞으면서 버티는 동안엔 회복 체감 거의 없음

RepairDelay
	•	RepairDelay = 2.5 sec
설명:
	•	마지막 피격 후 2.5초간 안 맞아야 수리 시작
	•	이 값이 너무 짧으면 장갑이 너무 쉽게 유지됨
	•	너무 길면 자동회복 의미가 사라짐
2.5초면:
	•	잘 피한 보상이 느껴짐
	•	탄막전에서 완전 관대하지도 않음

3. 추가로 꼭 필요한 값 2개
네가 적은 값만으로도 기본은 되는데, 밸런스를 맞추려면 사실 2개 더 있어야 한다.
BrokenRecoverThreshold
장갑이 얼마까지 회복되면 broken 상태 해제할지
추천:
	•	BrokenRecoverThreshold = 36
이유:
	•	기본탄 3발치 장갑
	•	장갑이 1만 차도 바로 정상 복귀하면 너무 가벼움
	•	최소한 “외판이 어느 정도 다시 붙었다”는 느낌 필요
계산:
	•	36 / 8 = 4.5초 회복 필요
	•	완전히 망가진 뒤엔 잠깐 잘 피해야 복귀 가능

HullDamageMultiplierWhenBroken
장갑 파손 상태에서 본체가 받는 긴장감 조절용
추천:
	•	HullDamageMultiplierWhenBroken = 1.25
즉 기본탄 12가 본체에는
	•	15 damage 정도로 들어감
이유:
	•	장갑이 깨졌는데도 평소랑 똑같이 맞으면 긴장감이 약함
	•	하지만 너무 높이면 바로 터져서 스트레스
	•	1.25배 정도가 적당

4. 실제 전투 체감
위 값으로 보면:
장갑 상태일 때
	•	기본탄 1발 = 장갑 12 감소
	•	장갑 120 → 약 10발 버팀
장갑 파손 후
	•	본체 100
	•	장갑 없는 상태에서 기본탄 1발 = 약 15
	•	대략 6~7발이면 격추
이 구조면:
	•	장갑 있을 때는 실수 허용
	•	장갑 깨지면 급격히 위험
	•	하지만 잘 피하면 다시 회복 가능
좋은 긴장 곡선이 나옴

5. 몬스터 데미지 등급 기준도 같이 정해두자
기본탄 12를 기준으로 적 패턴을 이렇게 나누면 편하다.
경탄
	•	8
	•	벌떼탄, 약한 산탄, 잔탄
기본탄
	•	12
	•	가장 흔한 탄
중탄
	•	18
	•	느리지만 아픈 탄
강탄
	•	28
	•	레이저, 폭발탄, 낙하탄 직격
대형 패턴
	•	40~55
	•	보스 필살기급, 대신 피하기 쉽게 예고 강하게
이렇게 나누면 패턴 설계가 쉬워짐

6. 가장 추천하는 시작 세팅
진짜 첫 프로토타입용으로는 이걸 추천

BaseBulletDamage = 12

HullHP = 100
ArmorHP = 120
ArmorBroken = ArmorHP <= 0

RepairRate = 8
RepairDelay = 2.5

BrokenRecoverThreshold = 36
HullDamageMultiplierWhenBroken = 1.25


7. 왜 이 수치가 좋은가
이 세팅의 장점:
	•	초보도 1~2번 실수로 즉사하지 않음
	•	고수는 장갑 관리 플레이 가능
	•	회복이 있지만 무한 탱킹은 안 됨
	•	장갑 파손 순간이 명확한 위기 구간이 됨
	•	몬스터 기본탄/강탄 차이를 만들기 쉬움

8. 한 가지 주의
이건 출발점으로 좋은 값이지, 최종 밸런스는 아니다.실제로는 아래 3개 보고 조정하게 될 거다.
	•	평균 전투 시간
	•	초보 유저 장갑 파손 빈도
	•	장갑 파손 후 생존 시간
보통 플레이해보고
	•	너무 쉽다 → RepairDelay를 3.0으로
	•	너무 어렵다 → ArmorHP를 140로
	•	장갑 깨지면 너무 바로 죽는다 → 본체 피격 배수를 1.1로
이런 식으로 미세조정하면 된다.
